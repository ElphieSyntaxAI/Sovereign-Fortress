# P2 — MSGF Governance  
**MSGF v3.2 · Universal Governance Pillar**

This document governs **P2 only**. It must not define raw telemetry capture (P1), stylometric identity (P3), temporal state machines (P4), immutable narrative logs (P5), or semantic retrieval (P6).

---

## 1. Scope

**Logic of Modality (LOM) Gates:** declarative checkpoints that regulate **which state transitions and which logic deltas** may proceed.

**Master Directive:** the non-overridable rule stack that LOM gates enforce before side effects commit.

---

## 2. Universal definitions (authoritative for P2)

| Term | Definition |
|------|----------------|
| **Consensus Protocol** | Dual-model convergence (e.g., Claude + Gemini) with an explicit aggregate verdict path before any “accepted” delta is minted. |
| **THE VAULT** | The approved lineage ledger: only deltas that pass consensus **and** pre-flight may enter. |
| **THE HALL** | The negative index of rejected logic patterns; pre-flight must scan here before promotion. |
| **Pre-flight** | Deterministic + model-assisted scan whose sole job is **gate readiness**, not long-form narration. |

---

## 3. Logic (mandatory behaviors)

1. **No orphan deltas:** no change enters **THE VAULT** without recorded consensus artifacts and a Hall scan outcome.
2. **LOM tags:** sequential processes that cross trust boundaries must declare `<GATE>` / `<STATE_LEDGER>`-class markers in spec or code comments so steps cannot be skipped silently.
3. **Supreme Court posture:** P2 rules **lineage of logic** (why a delta is admissible), not the biometric content of user keystrokes.
4. **Escalation:** on repeated disagreement or tie-breaker conditions, halt progression per Master Directive—without fabricating telemetry (P1) or rewriting audit trees (P5).
